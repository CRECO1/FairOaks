## 3. Deliberately deferred (and why)

| Item | Why |
|---|---|
| **Server-issued form-timer ticket** (audit M9 "bot guard trusts the client timer") | A signed ticket can still be beaten by waiting 3 seconds, and requiring it would silently drop leads from visitors with cached old JS. Your standing rule is reCAPTCHA/guards must fail open. Real bounds were added instead (per-contact limits, caps, rate limits). |
| **CSP `script-src 'unsafe-inline'`** | Next's hydration needs it without a nonce-based CSP; moving to nonces is a larger change that needs browser testing. H2 is closed independently by the sandbox. |
| **Gmail scope reduction / key-derivation (scrypt) for `TOKEN_ENCRYPTION_KEY`** | Both force every user to re-consent / a full token re-encryption migration. Needs a planned window. |
| **Cron secret `!==` → constant-time in 25 files** | All fail closed, secrets are long random strings; a 25-file mechanical edit adds regression risk for no practical gain. New code uses `safeEqual`. |
| **Unsubscribe as GET (campaigns)** | Needs a product decision on the email links already sent. Listing-alert unsubscribe/confirm use GET-renders/POST-acts. |
| **Anon-callable `SECURITY DEFINER` helpers** (`crm_client_held`, `crm_deal_visible`, …) | Used inside RLS policies; revoking anon EXECUTE would make anon reads of those tables error. They need a valid UUID and reveal one boolean. |
| **`npm`: `tar` (critical), ~30 `@vercel/*` advisories** | Pulled only by the `vercel` CLI **devDependency** (build tooling, not in the deployed app). A major CLI bump belongs in its own change. |
| **Not fixed by the workers** (noted in their reports): envelopes GET list and some form-submissions list paths lack a Restricted-*listing* filter (hidden-*deal* filter present); Copilot tools (`editLoi`/`generateLoi`, 1,753-line `crm-assistant-tools.ts`) check workspace only; `form-submissions/[id]` PATCH stays workspace-open to keep send-time field trimming working; `send-now` takes `agent_id` from the body; `email-leads/sync` auto-enroll merge fields not escaped. | Outside the named routes / need a design call; worth a follow-up pass, none rated above Medium. |
| **`rows[0]` when a user has several Gmail accounts** | Writes are now scoped to the row used; choosing among several accounts is a feature question. |
